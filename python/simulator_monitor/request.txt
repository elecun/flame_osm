[역할]
- 시니어 프로그래머 역할로 python 프로그램을 개발
- 아키텍처 설계와 gui 디자인도 가능한 풀스택 개발자

[필수]
- pyqt6를 사용해서 mac과 ubuntu에서 실행 가능하도록 구현
- venv 가상환경에서 실행되어야 함
- 사용자가 설정할 수 있는 핵심 파라메터는 cfg 파일에 정의하여 사용자가 변경할 수 있도록 해야함
- 필요한 기능이 모두 구현되고 나면, 사용한 라이브러리는 pip freeze > requirment.txt로 정리해서 저장
- 아키텍처 설계에 따라 모듈화하여 개발하고, python 코드 파일을 기능과 역할에 따라 여러개의 파일로 분리해서 구현하는 것을 권장
- python 버전은 3.10 이상에서 실행될 수 있어야 함.


[구현 기능]
- 기본 gui는 2개로 구성. 하나는 사용자가 모니터링하고 조작할 수 있는 gui, 다른 하나는 피험자에게 시각적인 자극을 줄 수 있는 gui 화면으로 구성. 피험자가에게 보여지는 창은 전체화면으로 전환 기능 필요.
- gui는 qt6로 구현하되, ui파일을 생성하여 로드될 수 있도록 구현
- 최대 4대의 usb 카메라로부터 opencv를 사용해서 실시간으로 영상을 수신하여 화면에 표시하는데, 각 화면의 좌측상단에는 카메라 id를 표시
- advantech usb 4750-ce의 0번 채널 입력이 들어오면 presssed 라고 표시하고, 입력이 없으면 idle 이라고 표시되는 label을 gui 화면에 표시되는
- 피험자(subject)의 이름을 입력할 수 있는 edit 창을 gui에 표시되는
- start, stop 버튼을 우측하단에 만들고, 사용자가 start 버튼을 누르면 피험자의 피험자의 이름으로 된 디렉토리를 생성하고, 그 디렉토리의 하위에 시작하는 날짜와시간으로 된 디렉토리 생성. yyyymmddHHMMSS 형식
- start를 누르면 새롭게 만들어진 디렉토리에 4개의 카메라 영상을 동영상으로 기록, 동영상 포맷은 avi이고, 음성은 사용하지 않아. 파일은 cam_<id> 형식으로 명명.
- start를 누르면 새롭게 만들어진 디렉토리에 handle_switch.csv 파일을 생성하고, advantech usb타입의 daq(4750-ce)를 통해 신호가 입력될때마다 밀리초 단위의 시간을 실시간으로 저장.
- stop을 누르면 동영상을 포함하여 모든 데이터 기록을 중단하지만, 실시간으로 들어오는 영상을 gui 화면에 표시하는 것은 중단하지 않도록 해
- 프로그램을 실행하면 사용자가 조작할 수 있는 gui 창과 함께 피험자에게 실시간으로 보여지는 검정색 바탕의 화면을 만드는데, 해상도는 사용자가 cfg 파일에서 설정을 변경할 수 있도록 해.
- 피험자가에 실시간으로 보여지는 영상은 opencv를 통해 실시간으로 화면 구성이 바뀌도록 할꺼야. 시나리오 파일(.scenario)에 명시된 순서에 따라 화면에 표시하면 돼.
- 프로그램을 사용자가 종료하면 기록되고 있는 데이터를 정상적으로 안전하게 저장하도록 하고, 프로그램을 정상적으로 종료할 수 있어야 해.
- 프로그램 실행은 python run.py --config exp.cfg 로 기본 실행될 수 있도록 run.py를 만들어. cfg 파일은 사용자 정의 파라메터가 정의된 파일이고, 로드될때 파라메터를 읽어서 반영하도록 해.
- 저장되는 csv 파일에의 첫번째 컬럼은 timestamp 데이터이고, 밀리초단위로 시간을 기록해야 하며, 표현포맷은 모두 동일해야 해.
- 새롭게 eye tracker 장치를 사용하려고 해. pupil labs사의 neon이라는 제품으로 프로그램이 실행되면 장치를 검색해서 자동으로 연결해야 하고, 현재 연결 상태를 사용자 gui에 표시해.
- 사용자가 start를 누르면 neon 제품도 record를 시작하도록 하고, stop을 누르면 아이트래커 기록을 stop해야해.
- 장치를 찾지 못해도 이 프로그램은 실행되어야 하고, 대신에 eye tracker 장치를 찾지 못했다는 상태를 gui에 표시해줘야 해.
- 카메라 장치가 최대 4대까지 이지만, 연결이 불가능한 화면은 그냥 검정 바탕으로 두고, no camera라고 중앙에 표시해주면 돼.
- 동영상을 기록할때는 원본 영상을 바로 기록하면 되고, frame loss가 발생하지 않도록 4대의 카메라 제어는 독립적인 thread로 관리해야 해.
- 피험자에게 보여지는 화면에는 기본적으로 검정색 바탕이고, 아무런 시나리오를 실행하지 않은 상태에서는 아무것도 표시하지 않아야 해.
- gui에서 experimental controls status에 scenario 디렉토리에 있는 *.scenario 파일들을 사용자가 선택할 수 있도록 dropdown 메뉴로 표시해.
- gui에서 start를 누르면 선택된 시나리오가 재생되고, 시나리오 재생이 끝나면 자동으로 stop 상태로 전환
- 사용자가 start 또는 stop을 누르면 recording이 되고 있는지 실험상태를 표시할 수 있도록 하고, 헷갈리지 않도록 start과 stop버튼은 상태에 따라 둘 중에 하나만 활성화되도록 해
- 옵션으로 체크박스를 만드는데, sound feedback을 제공할 것인지에 대한 체크박스. 체크하면 사용자가 핸들 스위치를 누를때마다 소리가 재생되도록 해. 소리 파일은 cfg 파일에 파일명을 정의하돌혹 하고, mp3 또는 wav 파일등 사운드 플레이가 가능하도록 구성해.
- 프로그램이 실행되면 사운드 피드백으로 재생할 사운드는 미리 시스템에 로드해서, 빠르게 재생될 수 있도록 해. 사용자의 핸들 스위치 속도에 따라서 소리가 중복해서 재생될 수 었어야 해. 이때, 이전에 재생되던 사운드는 새로운 사운드와 믹싱되어 재생되지 않고, 이전 사운드가 중단되고 즉시 재생되어야 해.
