- 연결된 최대 4개의 usb 카메라 영상과 advantech usb-4750 핸들스위치 데이터를 동일한 타임스탬프(밀리초단위) 데이터를 모니터링하면서 실시간으로 레코딩하는 프로그램
- python으로 구현하고, gui는 pyqt6로 구현하며, 모든 의존성은 monitor 디렉토리의 venv 가상환경에 설치
- pyqt를 사용할때 gui는 별도의 ui 파일을 만들어서 로드하는 방식을 사용. 코드레벨에서 gui 사용은 최대한 하지말것.
- 외부에서 설정할 수 있는 부분은 default.cfg 파일에 정의해서 사용자가 변경할 수 있도록.
- 초기에 default.cfg 파일의 설정값을 읽어서 프로그램의 기본값으로 설정.
- 프로그램이 실행되면, 카메라 영상을 화면에 출력하고 pupil labs의 neon 아이트래커 장치를 찾아야 함
- default.cfg에는 neon eyetracker에 대한 정보가 있는데, ip는 192.168.18이 default야.
- 현재 시스템에는 듀얼 모니터를 사용하고 있는데, 하나는 모니터링 및 통제용이고 하나는 피험자에게 보여질 창이야. 왼쪽에 있는 모니터는 1920X1080해상도, 우측에 있는 모니터는 메인 모니터로 2560X1440 해상도.
- 프로그램을 실행하면 창 두개를 모두 띄우는데, 모니터링 및 제어는 메인 모니터에 띄우고, 피험자용 화면은 왼쪽 모니터의 전체 화면으로 띄워.
- 피험자용 화면은 검정 배경으로 처리.
- 모니터링 창 우측 하단에 record start, record stop 버튼이 있는데, 모든 장치가 연결되면 record start가 활성화
- 모니터링 창에는 현재 피험자 이름을 입력할 수 있는 edit box를 두고, 실험자가 record start를 누르면 모든 데이터가 실시간으로 기록. 이때 usb camera나 usb-4750 데이터는 물론이고 네트워크에 있는 아이트래커에도 기록을 시작하도록 해야해. eye tracker 제어는 pip에서 pupil labs 라이브러리가 있어.
- record start를 눌렀을때 입력한 현재 피험자 이름의 디렉토리를 record 디렉토리에 만들고, 그 안에 기록을 시작한 현재 날짜와 시간을 yyyymmdd_HHMMSS 형태의 디렉토리를 만들어서 기록되는 데이터를 저장.
- record stop하면 기록을 멈추도록 하는데, usb 카메라 연결은 끊지않도록 해서, 화면에 모니터링은 계속 되도록 해.
- 저장하는 데이터는 카메라 영상으로 camera_#.avi 파일(#은 카메라 번호)로 기록하고, 매 프레임별로 저장된 시각을 csv 파일로 저장해.
- usb-4750은 advantech DAQ 장치인데, IDI0에 신호선이 연결되어 있어. active low 방식이라 핸들 스위치 버튼이 눌려지면 low로 떨어져. 기록은 switch.csv 파일에 저장하는데, 두개의 컬럼 데이터를 넣고 첫번째 컬럼은 타임스탬프, 두번째는 0 또는 1. 0은 스위치가 떨어지는 시점, 1은 스위치가 눌리는 시점(rising edge)을 말해. 즉, 버튼이 눌러지는 시점과 떼는 시점이 기록된다는 의미.
- 핸들스위치 데이터를 읽는것은 handle_switch_test.py 코드를 참고하면 되고, handle_switch.md 파일에 설명되어 있을꺼야. 시스템에 일부 설치가 되어있으니 확인해서 재설치를 할필요 없을수도 있어.
- 사용자가 record start를 하면, 데이터 기록과 함께 피험자에게 시청각적 자극을 줄 수 있는 화면도 동시에 실행이 되어야 해.
- 피험자에게 보여질 화면은 시청각적 자극을 주는 실험 화면인데, 1920x1080 해상도의 동영상을 재생하도록 하자.
- 현재 사용할 동영상은 아직 정해지지 않았기때문에 기능만 만들어두고, default.cfg에 실험에 사용할 동영상 파일명을 입력하는 것으로 프로그램이 로드될때 해당 동영상이 미리 로드되도록 해.
- 중요한 것은 사용자가 record start 버튼을 누르면 해당 동영상이 재생되어야 하고, record stop하면 동영상 재생을 멈추지만 멈춘 위치에서 피험자 화면은 검정색 배경으로 나와야 해.
- record start를 누르면 scenario.csv 파일을 만들고, 시청각 자극으로 제시되는 동영상 파일의 매 프레임별 타임스탬프를 기록하도록 해.
- 동영상 파일은 scenario라는 디렉토리에 저장되어 있어.
- usb 카메라 모니터링화면은 1/4 크기로 축수된 화면이면 되고, 저장은 원본으로 되도록.
- 카메라 화면은 4개로 분할되어 있는데, 축소된 이미지 해상도를 그대로 유지하도록 하고, 모니터링 화면은 전체 화면일 필요 없어.
- 프로그램은 마지막에 테스트해서 정상적으로 시스템에서 로드되는지까지 확인해.
- scenario video test에 있는 버튼도 mouse over 되어있을때 색상을 변경하도록 해. 그리고, 비디오가
  재생되고 있는지 아닌지 그 상태도 표시하고. 
- 아이트래커는 기록이 아이트래커 장치에 저장되기 때문에, record start를 누르면 eyetracker.csv 파일에 record start를 누른 날짜와 stop한 날짜와 시간정보를 저장하도록 해.
